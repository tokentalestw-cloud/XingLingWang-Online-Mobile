🎴 卡牌詳細資訊代表意義解密

1. 名稱與陣營
2. 攻擊力
3. 獻祭數量
4. 卡牌效果
5. 星星數
1. 卡牌名稱與陣營

顯示卡牌名稱與所屬種族（如：喵喵賊、妖怪村莊、勇者公會）。同種族的卡牌常具備強效連攜能力！

2. ★點數 (星數/分數)

單位卡登場後能為該戰線累積星數得分！在對決對戰中分數最高者取得優勢。

3. ⚔️ 攻擊力 (ATK) / 🛡️ 盾 (Shield)

⚔️ 攻擊力：對決計算的主要戰鬥數值！
🛡️ 盾牌：具備防禦護盾的單位，在防守時能優先替我方擋下敵人攻擊打擊！

4. 祭品需求 (Tribute Cost)

召喚高星級的強大卡牌時，需要先獻祭戰場上現有的低星單位（0隻 / 1隻 / 2隻）。

5. 卡牌種類 (單位卡 vs 魔法卡)

單位卡：可召喚並駐紮在戰場行進行攻防對決。
魔法卡：可從手牌直接發動，提供強化、削弱或解場等強大戰術效果！
